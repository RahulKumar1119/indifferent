# Audit 001 - 2026-10-16

Scope: `frontend/src` (Angular 20 app). Mode: AFTER (post-build review, user opted in).
Nothing has been modified. Fix only the numbered items the user approves.

Priority = rule tier: Hard Gate → HIGH, Purpose-Gate → MEDIUM, Quality Locks → LOW.
Contrast ratios computed from source hex values. Mobile widths not browser-tested; R-03 assessed from code only.

## HIGH (Hard Gate violations)

1. **Em dash in user-facing strings - R-02.** Five shipped strings contain "—":
   `shorts-gallery.component.ts:151,289,1211`, `shorts-progress.component.ts:179`,
   `watermark.component.ts:521` (share text). Also in comments (lower stake):
   `profile.component.ts:424`, `watermark.component.ts:10,149,891,1012,1050`, `login.component.ts:190`.

2. **Placeholder images in production - R-23/R-38.** 12 `picsum.photos` images (landing:112,209;
   about:51,71; contact:51; blog:71,236,245,254,263; login:33,58) plus `via.placeholder.com` avatar
   (`account.component.ts:19`). login:58's alt "Preview of a generated quiz video" describes an image
   that does not exist - fabricated content claim on top of the placeholder.

3. **Dead "Browse Files" / "or click to browse" buttons - R-26.**
   `create-project/upload.component.ts:58` and `shorts/shorts-upload.component.ts:119` call
   `$event.stopPropagation()`, which cancels the parent dropzone's click handler - clicking the
   labeled button does nothing. The only working path is clicking the dropzone background.

4. **Newsletter form is a no-op - R-26.** `blog.component.ts:186`:
   `<form (submit)="$event.preventDefault()">` - Subscribe stores nothing, submits nowhere, and has
   no success/error state. Either capture leads or remove the form.

5. **Dead route link - R-24.** `profile.component.ts:82` links to `/settings`; no such route exists
   (`app.routes.ts`) → NotFound page. `SettingsComponent`, `HelpComponent`, `AccountComponent` are
   fully built but unrouted - dead code leading to a dead link.

6. **"Generate using my DNA" is a false promise - R-26/R-38.** `profile.component.ts:263-266` toasts
   "Generating with your Creator DNA" then navigates to upload - nothing in the create-project flow
   reads the DNA profile. The toast claims a capability that does not exist.

7. **Theme system is broken across half the app - R-34.** `theme.service.ts` defaults to dark
   ("Video tools feel premium in dark"); the toggle exists only in the shorts navbar. All paper pages
   (landing, dashboard, login, about, contact, blog, …) hardcode `bg-[#FAF7F2]` and ignore the theme;
   the codebase has only 2 `dark:` variants and 177 `bg-white` uses. First paint has no theme class
   (set post-bootstrap) → FOUC. `custom-theme.scss` forces `color-scheme: light` and an azure Material
   palette that matches neither half. Every shipped theme must actually work.

8. **Fabricated credit/time ledger - R-17.** `profile.component.ts:29-31` invent
   `CREDITS_QUOTA=500`, `COST_PER_PROJECT=18`, `COST_PER_CLIP=6`; "Time saved" is
   `videosCreated*8 + totalClips*3` minutes; "credits reset" counts to the 1st of next month. None of
   this comes from the backend - invented account state presented as fact.

9. **Fabricated processing progress - R-17.** `shorts-progress.component.ts` falls back to invented
   percentage weights when the server reports none, and `buildEta` returns a hardcoded "45s". The UI
   shows numbers that correspond to nothing.

10. **Missing loading states - R-27.** `dashboard.component.ts:121` and `projects.component.ts:71`
    render "No films yet. / No projects yet." immediately during fetch - users see a false empty
    state before data arrives. `preview.component.ts:134-136` conflates network failure with 404;
    `project-detail.component.ts:182` shows "Project not found." for any error.

11. **Contrast failures - R-25.**
    - `creator-stats.component.ts:61` stat number `#6D28D9` on dark glass ≈ **2.74:1** (fails even large-text). Dark is the default theme.
    - Indigo `#6366f1` as text on dark surfaces (`shorts-progress.component.ts:104` active stage label, `shorts-gallery.component.ts:481,500` "edited/customized" badges) ≈ 4.35–4.43:1 - fails normal text.
    - Same indigo on white (4.47:1) is borderline-fail; `--color-success` #10b981 (2.54) / `--color-error` #f43f5e (3.67) / `--color-warning` #f59e0b fail on white should those tokens ever land on a light surface.
12. **Dialog/focus keyboard gaps - R-32.** Profile dialogs (`profile-header.component.ts:126-130,209-213`) and the DNA dialog have no Escape + no focus trap; `confirm-dialog.component.ts` handles Escape only while focus is inside and never traps; profile deletion uses `window.confirm()` (`profile.component.ts:409`). Login inputs use `focus:outline-none` with a ~2.7:1 border replacement (`login.component.ts:125-130`); blog newsletter input's focus color is ~2:1 on its own background. Toasts have no close button, no Escape, whole-toast click only (`toasts.component.ts`). `role="radio"` tiles have no arrow-key/radiogroup behavior (`create-project.component.ts:85-127`); tabs lack arrow keys.

13. **Fake "connected accounts" state - R-38.** OAuth buttons set a placeholder handle and the page
    shows fabricated activity ("connected as @…" toast), while the panel text says integration is
    "coming soon". The toast claims connection that never happened.

14. **Fabricated structured data - R-36.** `shorts-maker.component.ts` JSON-LD `VideoObject` has no
    video, `uploadDate: '2026-10-03'` (invented), `duration PT1M`, and `logo.svg` as thumbnail.

15. **Unsourced statistics in copy - R-17.** Blog articles state "ten percent… sixty-five percent"
    retention figures and "millions of viewers" without sources; about page makes comparable
    performance claims. Numbers need a real source or removal.

## MEDIUM (Purpose-Gate)

16. **Aurora gradient orbs with endless loop - R-01.** `.aurora-bg` (`styles.css:71-85`) paints purple/blue radial gradients and animates infinitely (15s); instantiated globally (`app.html`) and again in profile. Purple/blue gradient = the lavender AI-startup look the design direction rejects.

17. **Purple/violet gradient dose - R-01/R-19.** Upload progress bars use indigo→purple gradients (`shorts-upload.component.ts:207`, `upload.component.ts:112`, `progress.component.ts:90`), video-card fallback is a rainbow gradient (`video-card.component.ts:37`), `.shimmer-text` is an infinite animated gradient (used on 404), `.glow-btn`, `.spotlight-card` radial. Individually small; together they define the second design language.

18. **Fourth palette conflict - R-01/R-29.** Paper palette (DESIGN.md) vs indigo `#6366f1` + `#7c3aed` theme-color (`index.html:29`) vs azure Material theme (`custom-theme.scss:12-14`) vs purple stat `#6D28D9`. Four systems, no arbitration. DESIGN.md already lists these as open decisions.

19. **Glass dose - R-10.** `glass-card` is used 45× across ~18 files; 22 `backdrop-blur` uses. The dose cap is 1–2 per page; here it is the default surface everywhere on the token half.

20. **Sparkles/zap icons - R-04.** `sparkles`: creator-dna ×2, profile-header, profile.service, profile toast; `zap`: ai-credits, creator-stats, shorts-maker. The exact AI default icon set, in the exact default contexts.

21. **Lucide-only iconography, reason undocumented - R-04.** 301 lucide references; DESIGN.md flags "Lucide use - write the reason or vary" as open. No written reason anywhere.

22. **Uppercase tracked eyebrow labels ×58 - R-06.** `uppercase tracking-[0.1–0.2em]` micro-labels are the app-wide section-label idiom (58 occurrences); R-06 lists this pattern as a tell when it's the default.

23. **Glow dose - R-13.** `.glow-btn` on 9 buttons (progress ×1, preview ×3, not-found, shorts-upload submit, upload submit, projects retry) plus the indigo dropzone glow. Glow is currently the primary button style, exceeding the 1–2 dose.

24. **Uniform stat-card grids - R-14.** Profile: 6 identical cards (icon, number, corner badge) + 6-card creator-stats row; dashboard: 4. Same card, different numbers - the template shape R-14 names.

25. **Arrows on multiple button types - R-08.** Landing tool cards, use-case rows, CTA, and dashboard "All projects →" links all add the arrow affordance. Keep it where it means "navigates deeper", drop the rest.

26. **Badge/pill stack - R-09.** "Studio access" pill with pulsing dot above the login headline, "AI pipeline" capsule badges on tools, "Free during beta" pill, "In-browser · Free forever" pill. Category labels as decorative badges.

27. **Soft-shadow dose - R-12.** Every elevation is a large soft shadow (dropdown `0_20px_60px`, hero image `0 24px 60px`, toast `shadow-2xl`, hover lifts). No hard/short values anywhere; shadows became wallpaper.
